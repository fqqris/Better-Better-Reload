# BETTER-BETTER-RELOAD

This is a really bad fork of Better-Reload by Benzi with more customization options and some better systems, which includes: 

- **Shop V2** Scrollable rows in the Item Shop with the ability to add more sections
- **Item Refunding** Of previous shop purchases, will use a refund ticket if you refund the item in the time allowed which I think is configurable
- **Arena** Gamemode with live score and score saving
- **Automatic Item Shop Rotator** Will automatically update the item shop for that day
- **XMPP** For interacting with friends, parties and gifting
- **Client Settings** Saves every clients settings after backend restarts or game crashes
- **Item Shop Bundles** Create bundles with custom names, items and more
- **Shop Tags** Tags that appear above any item like ***NEW!***, ***ONE TIME OFFER!***, ***REACTS TO MUSIC*** are all available
- **Semi-Matchmaking Bans** - The matchmaker immediately kicks anyone with a matchmaking ban applied out of the queue

## SETUP 

Head over to `Config/config.json` and configure all options that are there including moderators, discord bot and more. 
Head back over to the main file and run `start.bat`, everything else including installing dependencies is automatically done for you

## DISCORD BOT COMMANDS

`create` Creates your account using random numbers and letters
`latency` Check the backends latency
`itemsfill` Gives a user every item in the game
`permissionadd` Gives a user backend permission
`ban` Bans a user

- *Note: I removed almost every command from this to not rely on discord but a dashboard which I have not included so sorry for that*
